# 骑行训练 PWA 使用文档

这是一个本地优先的个人训练工具，适合每天快速查看训练、记录身体数据、同步训练摘要、导出备份。应用没有登录和服务器数据库，训练、身体、打卡、AI 设置等数据都保存在当前浏览器本地。

## 添加到桌面

### iPhone / iPad

1. 用 Safari 打开生产地址。
2. 点底部分享按钮。
3. 选择「添加到主屏幕」。
4. 从主屏幕图标打开后，会以 PWA 独立窗口运行。

### Android

1. 用 Chrome 或 Edge 打开生产地址。
2. 点浏览器菜单。
3. 选择「安装应用」或「添加到主屏幕」。
4. 如果应用内出现「安装应用」按钮，也可以直接点击。

## 今日

- 顶部优先显示今日备忘，适合作为临时提醒。
- 今日计划展示训练类型、时长、目标功率、力量动作和备注。
- 推荐饮食会按当天训练类型显示训练前后建议。
- 底部快捷打卡用于记录训练完成、蛋白质、晚餐控制和早睡。
- AI 疲劳分析会保存最后一次结果，切换页面后仍能看到。

## 计划

- 默认进入本周，并自动定位到今天。
- 顶部进度点显示本周每天完成状态，点击某个点会滚动到对应日期并展开当天卡片。
- 每天的计划默认折叠，只保留日期、训练类型、完成状态和摘要；点击「展开」后编辑模板、标题、时长、备注和实际完成记录。
- RPE 使用带文字描述的选项，方便按体感记录训练强度。
- 「AI 咨询」只适合问训练计划、恢复、骑行、力量和执行记录相关问题。
- AI 生成的计划需要先预览，点击应用后才会覆盖本周计划。

## 日历

- 月视图可以查看每天训练完成情况。
- 选中日期后可以记录当天备忘。
- 配置 Intervals.icu 后，可以同步单日或本月训练摘要。
- 应用只保存同步后的摘要分析和实际完成字段，不保存原始活动数据。

## 身体

- 使用周日历切换日期，记录体重、体脂率、腰围、胸围和备注。
- 设置页录入身高后，身体页会计算 BMI 并标记区间。
- 趋势图在身体记录下方，支持按天、周、月、年查看体重和腰围趋势。

## 设置

- 主页只保留 FTP、身高、训练目标、添加到桌面和数据管理。
- 「外部 API 与 AI」在子页面里配置 Intervals.icu 和 ChatGPT 兼容接口。
- 「训练模板」在子页面里维护模板，力量训练是单独开关，可以和恢复、Z2、甜区、阈值等组合。
- 数据管理可以查看本地数据量、导出 JSON、导入 JSON 和清空本地数据。

## 备份建议

- 长期记录建议每周手动导出一次 JSON。
- 导入 JSON 前，应用会先自动导出当前数据，避免误覆盖后无法恢复。
- 清空本地数据有二次确认；清空后只能用之前导出的 JSON 恢复。

## 隐私说明

- 训练、身体、打卡、备忘和 API Key 保存在当前浏览器本地。
- 外部同步和 AI 只会在你点击对应按钮后发起请求。
- API Key 保存在当前浏览器本地，请不要在公共设备上使用。
- 网站已接入 51.LA 访问统计，页面访问会加载第三方统计脚本；训练和身体数据不会由本应用主动提交给 51.LA。
